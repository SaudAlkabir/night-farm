# مزرعة الليل 🌾🌙

لعبة نجاة ثنائية الأبعاد في المتصفح: ازرع في النهار، وابنِ بيتك، واصمد في الليل ضد المصابين والذئاب… وابنِ جهاز الإرسال لتصل للمنطقة الآمنة.

## العب الآن
افتح الرابط: **https://SaudAlkabir.github.io/night-farm/**

## العب بدون إنترنت
حمّل الملف `Night-Farm.html` (أو النسخة المضغوطة `Night-Farm-mini.html`) وافتحه في المتصفح.

- تقدّمك يُحفظ في متصفحك.
- يشتغل على الكمبيوتر والجوال (أندرويد وآيفون).
